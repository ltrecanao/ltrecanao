## Purple 💜

**[PurpleMD](https://md.purple.com.ar)**: editor Markdown liviano, autohospedado y de código abierto. Vista previa en vivo, exportación a PDF, Google Auth y Drive, e integración con MCP.

**[PurpleBoard](https://board.purple.com.ar)**: pizarra colaborativa peer-to-peer, open source y 100% estática. Creá notas, dibujá, conectá ideas y sumá imágenes mientras hablás con otras personas en tiempo real, sin backend y sin registro.

**[Purple3D](https://3d.purple.com.ar)**: visualizador 3D de paneles de **steelframing**, **drywall** y **woodframing**. Armado paso a paso, panelizado, control de faltantes y sobrantes y listado de corte exportable. Funciona en el navegador sin instalar nada.

> ⚠️ Purple3D: Solo para visualizar. No reemplaza el plano ni el cálculo estructural.
